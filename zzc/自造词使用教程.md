# 自造词使用教程

本文对应当前版本的天行键、星猫键道自造词（ZZZC）功能。第一次使用只需记住：**输入自造词 → 收起键盘 → 重新部署 → 运行合并工具 → 再重新部署**。后文再按自己的设备阅读同步步骤。

## 先看最简单流程

每次要永久保存自造词，都按这个顺序：

1. 输入自造词。
2. 收起键盘或结束当前输入。
3. 重新部署。
4. 运行对应系统的词库合并工具。
5. 把合并结果同步或复制回输入法，再重新部署。

只想临时使用新词时，做到第 3 步即可。

说明：文件名带 `.zzc.dict.yaml` 的是待合并文件，`zzc_state/` 是配套文件夹；“方案目录”就是放有 `txjx`、`xmjd6` 等方案文件的文件夹。需要复制或同步时，按教程一起处理。

## 第一次怎么造一个词

假设要把“测试词”放到编码 `bmms`：

```text
bmms\测试词\
```

最后一个 `\` 表示“完成”。如果 `bmms` 已有首选词，新词会替换首选；如果只想把它放到重码候选后面，使用：

```text
bmms\+测试词\
```

完成输入后先收起键盘，再重新部署。只想临时使用时，到这里即可；要永久保存，再运行后文的合并工具。

## 使用前注意

- 自造词入口键是 `\`，大多数操作也用第二个 `\` 确认。
- 下文的“编码”指目标词码，例如 `bmms`；“数字”指候选序号（候选左侧显示的数字）。
- 单字不能用自造词保存。二字词支持 4-6 码，三字词支持 3-6 码，四字及以上词支持 4-6 码。
- 自造词状态下可以使用顶功、数字、空格等方式选字。
- 词中可以包含逗号和句号。标点会保留在词中，但不参与编码和码长计算；输入第二个 `\` 后才结束造词。
- 手机皮肤可能通过上划等手势触发 `\`。只要能进入自造词状态即可。

## 当前可用操作

| 输入形式 | 作用 |
| --- | --- |
| `编码\词\` | 在空码新增词，或替换当前编码首选 |
| `编码\+词\` | 把新词追加为当前编码的重码候选 |
| `编码\-\` | 删除当前编码首选 |
| `编码\-数字\` | 删除当前编码第几个候选 |
| `编码\数字\` | 把当前编码第几个候选调整为首选 |
| `编码\<\` | 把当前编码首选前移一码 |
| `\--\` 或 `编码\--\` | 撤回本次尚未保存的最近一次操作 |
| `\!!!\` 或 `编码\!!!\` | 清空全部未合并操作 |

候选序号以当前屏幕上看到的候选顺序为准。`编码\数字\` 中的“数字”直接换成候选序号，例如 `bmms\2\`；删除候选时写成 `bmms\-2\`。

### 新增、替换和追加

```text
编码\词\
编码\+词\
```

使用 `编码\词\` 时：

- 目标编码为空码，直接新增。
- 目标编码已有首选，新词替换首选，原首选按规则向更长编码顺延。
- 新词如果原来已经存在于其他编码，系统会自动处理重复位置。

使用 `编码\+词\` 时：

- 新词排在已有候选后，不替换首选。
- 追加数量不受固定重码数限制。
- 新词如果原来已经存在于其他编码，系统会自动处理重复位置。
- 电脑上进入该操作后，直接按 `=` 键即可输入 `+`，不需要按 `Shift+=`。

### 删除、调序和前移

```text
编码\-\
编码\-2\
编码\2\
编码\<\
```

- 删除后同码仍有候选，下一候选原位接替。
- 删除后如果需要补位，系统会自动处理。一般不需要手动处理。
- `编码\数字\` 只调整当前编码的候选顺序。
- `编码\<\` 把首选向短码移动一码，最短不能低于该词允许的合法码长；目标码已有词时会自动顺延。
- 电脑上进入前移操作后，直接按 `,` 键即可输入 `<`，不需要按 `Shift+,`。

### 撤回和清空

```text
\--\
编码\--\

\!!!\
编码\!!!\
```

- 撤回只处理本次输入中、还没有因收起键盘而保存的最近一次操作；已经保存或合并的内容不受这条指令影响。
- 清空会移除全部未合并操作，影响范围较大；电脑输入 `!` 需要按 `Shift+1`。
- 已经运行合并工具的结果不能用这里的撤回操作恢复，应运行对应平台的“撤回合并”工具。它会从合并前备份中恢复整套文件。

## 从造词到正式生效

无论使用哪种设备，完整流程都遵循下面的顺序。

### 1. 保存本次操作

1. 使用自造词功能新增或调整词汇。
2. 结束当前输入会话。手机端先收起键盘；电脑端结束当前输入会话。
3. 再执行重新部署，让输入法整理待合并文件（`*.zzc.dict.yaml`）。

不要在键盘仍打开时立即复制文件，否则本次操作可能还没有保存完成。

### 2. 运行合并工具

按系统选择 `zzc` 目录中的入口：

| 平台 | 合并 | 撤回合并 |
| --- | --- | --- |
| Windows | 双击 `Win_词库合并.exe` | 双击 `Win_撤回合并.exe` |
| macOS | 运行 `python3 zzc/Mac_词库合并` | 运行 `python3 zzc/Mac_撤回合并` |
| Linux | 运行 `python3 zzc/Linux_词库合并.py` | 运行 `python3 zzc/Linux_撤回合并.py` |
| iOS | 用 a-Shell 或 Pythonista 运行 `iOS_词库合并.py` | 需要时在电脑端使用对应撤回工具 |

合并工具可以放在方案根目录，也可以保留在方案的 `zzc/` 目录。它会查找同目录或上级目录中的 `*.zzc.dict.yaml`。

合并工具会把自造词正式写入词库，并生成供其他设备清理旧临时记录的同步标记。用户不需要手动编辑或删除这些文件。

### 3. 把合并结果送回输入设备

1. 把合并后的方案文件和 `zzc_state/` 同步或复制回输入法方案目录。
2. 等待文件传输完成后重新部署。
3. 回到输入场景，首次唤起键盘，让输入法自动清理旧临时记录。
4. 检查新词和候选顺序，再开始下一轮造词。

不要手动删除整个 `zzc_state/` 文件夹。

## 元书：不使用 iCloud

### 初次准备

把 [`include_keyboard_rime_files.txt`](../include_keyboard_rime_files.txt) 和方案文件放在同一目录。不要复制或同步 `build/`。

### 日常流程

1. 在手机上使用自造词。
2. 收起键盘，再到元书中重新部署。
3. 把整个方案目录复制到电脑；不要复制 `build/`。
4. 在电脑上运行对应系统的词库合并工具。
5. 把合并后的方案文件和 `zzc_state/` 复制回元书方案目录。不确定文件范围时，可以复制整个方案目录，但仍排除 `build/`。
6. 在元书中重新部署，再进入输入场景唤起一次键盘。
7. 检查结果正常后继续使用。

## 元书：使用 iCloud

### 初次准备

1. 把下面 3 个同步清单文件放到方案目录：
   - [`include_keyboard_rime_files.txt`](../include_keyboard_rime_files.txt)
   - [`exclude_iCloud_rime_files.txt`](../exclude_iCloud_rime_files.txt)
   - [`include_iCloud_rime_files.txt`](../include_iCloud_rime_files.txt)
2. 在元书的 `RimeUserData` 下建立方案目录，例如 `txjx` 或 `xmjd6`。
3. 把方案文件和同步清单放入该目录，再把方案目录放入 iCloud。
4. 等待 iCloud 完成首次同步。

不要把 `build/` 放入 iCloud。

### 手机造词、电脑合并

1. 在手机上完成本轮自造词操作。
2. 收起键盘，确保当前输入会话结束。
3. 到元书中重新部署，让手机里的待合并内容进入元书文件。
4. 在元书右下角菜单执行 iCloud 上传。
5. 等待电脑端出现最新的 `*.zzc.dict.yaml`。先核对文件修改时间，再开始合并。
6. 在电脑端对应方案目录运行词库合并工具。
7. 等待合并后的方案文件和状态文件完成 iCloud 同步。
8. 回到元书重新部署，再进入输入场景首次唤起键盘。
9. 检查新词已经可以正常输入。

### iCloud 同步注意

- iCloud 有延迟。每次合并前后都应核对文件修改时间，不要只看目录是否存在。
- 电脑刚完成合并时，不要立刻在手机开始下一轮造词；先等方案文件同步完成。
- 第一次重新部署没有看到变化时，先等待 iCloud 完成同步，再重新部署一次。
- 元书提示正在复制 iCloud 文件，通常表示新文件正在进入应用目录，应等待操作结束。
- 长时间没有变化时，到 iOS“文件”App 检查元书的 iCloud 目录和文件修改时间。

## iOS 本机直接合并

不想经过电脑时，可以在 iOS 上直接运行合并工具：

- 免费方案：按 [a-Shell 快捷指令合并说明](a-Shell快捷指令合并说明.md) 配置。
- Pythonista：按 [iOS 快捷指令合并说明](iOS快捷指令合并说明.md) 配置。

首次配置必须选择最终合并目录：

- 使用 iCloud，选择 iCloud 中的 `RimeUserData` 或具体方案目录。
- 不使用 iCloud，选择输入法应用文件中的 `RimeUserData` 或具体方案目录。
- `zzc_state/` 必须和方案文件放在同一处。不要把方案放在 iCloud、状态文件放在应用本地，或反过来。

## 电脑用户与同步助手

只在电脑本机使用时：

1. 使用自造词。
2. 结束当前输入会话并重新部署。
3. 运行词库合并工具。
4. 再次重新部署并检查结果。

需要在 Windows 和 iCloud 之间同步时，可以使用 [天行键同步助手](https://github.com/wzxmer/folder-sync-mirror)；星猫键道也可使用。

- 按同步助手说明设置 iCloud 方案目录和本机 Rime 目录。
- 使用同步助手的“立即合并”时，以本机同步目标中的待合并操作为准。
- 同一批操作不要同时运行同步助手“立即合并”和手工合并工具，避免重复处理或覆盖新旧文件。
- 等同步助手完成同步后，再重新部署并首次唤起键盘，让输入法自动清理旧临时记录。

## 仓输入法

仓输入法可以使用自造词，但同步方式与元书不同，建议使用手动导出流程。

使用前注意：

- 不建议为这套流程开启仓的 iCloud 同步。
- 不要长期打开“部署时覆盖键盘词库文件”。
- 把 `Hamster.yaml` 和方案文件放在同一目录。该文件会保留自造词所需的键盘文件，避免重新部署时丢失操作。

日常流程：

1. 在手机上使用自造词，然后收起键盘。
2. 打开仓输入法文件管理，在通用功能中执行“使用键盘文件覆盖应用文件”。
3. 重新部署，把待合并操作整理到 `*.zzc.dict.yaml`。
4. 在 iOS“文件”App 的 `我的 iPhone/Hamster/Rime` 中导出方案词库和 `zzc_state/`。
5. 在电脑上运行对应系统的词库合并工具。
6. 把合并后的方案文件和 `zzc_state/` 放回仓输入法对应目录。
7. 重新部署，再进入输入场景首次唤起键盘。

只想临时使用新词时，完成第 3 步即可继续输入；需要永久写入正式词库时，再完成后续合并流程。

## 安卓及其他平台

当前没有安卓设备实测，下面只提供通用步骤：

1. 结束输入会话，再重新部署。
2. 导出待合并文件、方案文件和整个 `zzc_state/`。
3. 在支持的平台运行合并工具。
4. 把合并后的方案文件和 `zzc_state/` 放回输入法。
5. 重新部署并首次唤起键盘，让输入法自动清理旧临时记录。

## 合并频率建议

- 不需要每造一个词就重新部署或合并。
- 每天经常造词，可以每月合并一到两次；短期大量调整时可提前合并。
- 出现待合并数量提醒时，应尽快结束输入会话、重新部署并完成合并，不要继续长期累积。
- 合并前先确认同步完成；合并成功后先确认结果已回到输入设备，再开始下一轮操作。
